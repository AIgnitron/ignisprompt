## Patch Fixes

#141 is a post-v0.1.1 MCP compatibility fix. MCP tools/call results expose `structuredContent`, and strict MCP clients or SDKs may expect that field to be a JSON object.

For the experimental stdio MCP `audit_events` tool, `structuredContent` now returns:

```json
{
  "events": []
}
```

instead of a raw JSON array. The `events` array contains the same recent local audit metadata exposed before the patch.

Boundaries:

- The HTTP `GET /v1/audit/events` response remains the existing JSON array shape.
- No new MCP tools were added.
- No MCP behavior beyond response wrapping changed.
- No HTTP API behavior changed.
- MCP observability tools remain read-only and local-only.
