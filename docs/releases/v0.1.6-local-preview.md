# Local Preview v0.1.6 Release Record

Release status: published local-preview release. `v0.1.6-local-preview` is the current latest local-preview release. This document records the released local operator workflow arc after `v0.1.5-local-preview`.

## Summary

`v0.1.6-local-preview` is a narrow local preview release for the local operator workflow arc after v0.1.5. The focus is the Aethra Local Operator Console, `ignispromptctl operator-summary`, local operator packages, `scripts/operator-check.sh`, `make operator-check`, and conservative package validation, redaction, and path-safety checks.

The default path remains local-only and no-model friendly. It does not require Ollama, GGUF tooling, external model weights, cloud credentials, telemetry, global aggregation, or external services for the default build/test/smoke workflow.

## What Changed Since v0.1.5-local-preview

- Added the Aethra Local Operator Console for fixture-backed local preview operator workflow guidance.
- Added `ignispromptctl operator-summary` and `ignispromptctl operator-summary --json`.
- Added local operator package generation under ignored `local-evidence/operator/` paths.
- Added local operator package list and validation behavior.
- Added safe operator package Markdown and JSON summary files.
- Added Aethra read-only operator package preview from fixture-backed data.
- Added `scripts/operator-check.sh` and `make operator-check`.
- Extended the local evidence demo workflow to include operator package generation, listing, and validation.
- Added conservative operator package validation, redaction, and path-safety checks.

## CLI Notes

- `ignispromptctl operator-summary` remains local preview operator workflow guidance only.
- `ignispromptctl operator-summary --json` emits safe structured guidance without prompts, raw audit text, generated evidence contents, daemon URLs, hostnames, usernames, absolute filesystem paths, private credentials, or local machine-specific values.
- `ignispromptctl operator-summary --package-output local-evidence/operator/<name>` writes a local operator package under an ignored path.
- `ignispromptctl operator-summary --package-list local-evidence/operator/<name>` inspects package files locally.
- `ignispromptctl operator-summary --package-validate local-evidence/operator/<name>` runs structural/local package validation only.
- Operator packages are local-only helper outputs. They are not signed, not certification, not attestation, not production evidence, and not release approval.

## Aethra Notes

- Aethra remains fixture-backed by default.
- Live-local loading remains manual.
- Aethra Local Operator Console remains read-only.
- Aethra command snippets remain copy-only. The console does not execute commands.
- Operator summary cards and package status values remain status hints, not controls.
- Aethra operator package preview is a read-only local preview aid.
- Aethra does not upload, extract archives, read arbitrary local paths, persist package data, poll, add telemetry, add cloud calls by default, add global aggregation, or add model or runner controls.

## Operator Package Notes

- Package output must stay under ignored `local-evidence/operator/` paths.
- Package files are intended for local preview review and demo notes.
- Package validation is structural local validation only.
- Package validation does not provide certification, compliance approval, release approval, signed attestation, tamper-evident audit storage, cryptographic verification, supply-chain certification, or production deployment approval.
- Generated operator packages, readiness packages, evidence bundles, archives, audit logs, local evidence, model weights, SBOM outputs, `target/`, and Aethra `dist/` output must stay ignored and uncommitted.
