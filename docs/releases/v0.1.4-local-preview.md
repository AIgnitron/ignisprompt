# Local Preview v0.1.4 Release Readiness

Release status: draft. `v0.1.3-local-preview` remains the current latest local-preview release. This document prepares the next local preview release package after `v0.1.3-local-preview`. Do not tag or publish `v0.1.4-local-preview` yet.

## Summary

`v0.1.4-local-preview` is the next narrow local preview release package after `v0.1.3-local-preview`. The focus is the local evidence workflow and Aethra demo-readiness arc: archive handling, bundle inspection, report export, guided navigation, workflow automation, regression checks, and a safer local command center.

The default path remains local-only and no-model friendly. It does not require Ollama, GGUF tooling, external model weights, cloud credentials, telemetry, or external services for the default build/test/smoke workflow.

## What Changed Since v0.1.3-local-preview

- Added the CLI evidence archive workflow for local-only bundle archiving and archive verification.
- Added the Aethra evidence bundle viewer for manifest, validation summary, archive metadata preview, and local preview report export helpers.
- Polished the Aethra evidence workflow and aligned the CLI demo path with the new bundle contract.
- Added the Aethra evidence report export helpers for Markdown and JSON report output.
- Added guided Aethra demo navigation so the safe walkthrough flows from overview to routing, audit review, model and runner hints, evidence, and sustainability preview.
- Added the repeatable local evidence demo workflow script with dry-run and self-test modes.
- Added the local evidence workflow regression check to keep CLI bundle help and Aethra boundary wording aligned.
- Added the Aethra Local Command Center with safe command recipes, an evidence workflow checklist, and demo readiness notes.

## CLI and Bundle Notes

- `ignispromptctl evidence-bundle` stays local-only and writes output under ignored `local-evidence/` paths.
- `--include-audit-events` stays explicit. `--json` prints structured JSON. `--list`, `--validate`, `--archive`, `--verify-archive`, and `--print-manifest` operate on existing bundle or archive paths and do not require daemon access for read-only inspection.
- Bundle metadata stays conservative: local preview only, local-only, non-certified, not signed, and not production attestation.
- Archive output stays local-only and ignored by default guidance. Archive verification is structural local validation only, not cryptographic verification.

## Aethra Local Preview Improvements

- Fixture mode remains the default.
- Live-local loading remains manual and loopback-oriented.
- The local preview banner keeps the no-telemetry, no-cloud-by-default, non-production boundary visible.
- Overview diagnostics continue to distinguish fixture mode, live-local readiness, successful local connection, unreachable daemon, unavailable endpoints, invalid response shapes, failed refreshes, and successful refreshes.
- The Guided Demo Path now leads through overview, the local command center, route explorer, audit events, model and runner status, evidence bundle review, and sustainability preview.
- The Local Command Center groups safe CLI recipes, an evidence workflow checklist, and demo readiness notes for browser-local review.
- Local command helpers remain copy-only browser clipboard actions. Aethra does not execute commands.
- Empty states continue to explain missing fixture or live-local data and the next local action to try.

## Aethra Evidence Reports

- Aethra evidence reports remain browser-generated from displayed local preview data.
- Reports stay local-only and do not persist to localStorage or sessionStorage.
- Reports exclude prompts, raw request text, raw audit event bodies, PII, machine identifiers, hostnames, usernames, filesystem paths, secrets, and API keys.
- Report output remains conservative: local preview only, local-only, non-certified, not signed, not production attestation, and not cryptographic verification.

## Local Workflow Automation

- The repeatable local evidence demo workflow script exercises route-explain, audit-events, evidence bundle generation, listing, validation, archiving, archive verification, and manifest inspection under ignored local-evidence paths.
- Dry-run mode prints the planned workflow without starting the daemon.
- Self-test mode verifies ignored-path handling and command construction without requiring a live daemon.
- `make evidence-check` keeps the workflow contract, help surface, and Aethra boundary wording aligned without external services.

## MCP Improvements

- The experimental stdio MCP stub still uses newline-delimited JSON-RPC over stdio.
- `tools/list` continues to advertise `route_explain`, `audit_events`, `status_version`, and `sustainability_summary`.
- The observability tools remain read-only and local-only. They do not add model controls, runner controls, config changes, cloud fallback, command execution, prompt/resource/sampling support, remote transports, telemetry, persistence, uploads, or external lookups.
- This is not a complete MCP implementation and is not broad MCP client compatibility.

## API and Schema Hardening

- Local preview schema locks continue to cover health, model manifests, model and runner status hints, daemon version and status metadata, audit events, sustainability metrics, invalid sustainability period errors, chat completion response shapes, and MCP response envelopes.
- Chat completion schema locks continue to cover non-streaming responses, streaming SSE chunks, route metadata, local-only route flags, UTF-8-safe streaming fragments, and representative invalid input errors.
- The audit-events and route-explain CLI coverage remains read-only and local-only.
